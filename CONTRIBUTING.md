# Contributing

Contributions and improvements are welcome.

## Development

Install the dependencies:

```bash
python3 -m pip install -r requirements.txt
```

Run the test suite:

```bash
python3 -m pytest -q
```

For local development, configure the gateway through environment variables. Do not commit credentials or other secrets.

## Pull requests

Please keep changes focused, include tests for new behavior where practical, and update the documentation when configuration or behavior changes.
